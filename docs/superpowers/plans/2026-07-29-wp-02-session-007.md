# WP-02 SESSION-007 Organization Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a real PostgreSQL-backed organization create/list/edit journey
that makes Learning Hub visibly useful while preserving the approved
React Aria/shadcn foundation.

**Architecture:** Add an `organizations` bounded-context module with pure domain
decisions, owned Drizzle schema, transaction-scoped repository/service, thin
Next.js route adapters, and server-first UI. Identity is consumed only through
its public exports; transactional audit and versioned outbox events remain
inside the organizations module.

**Tech Stack:** Next.js 16.2.11, React 19.2.6, TypeScript 5.9, React Aria/shadcn
`aria-nova`, Tailwind CSS v4, Drizzle ORM, PostgreSQL/Neon, Vitest, Playwright.
